# Post Constructor — @tadhayrapetian

Конструктор постов для Instagram: 27 макетов, автоматическая генерация цветовых
палитр, полностью в браузере — ничего не отправляется на сервер, весь контент
остаётся у тебя.

## Как открыть

Просто открой `index.html` в любом браузере (Chrome, Safari, Edge). Ничего
устанавливать не нужно — это один самодостаточный файл.

### Как приложение на Mac (без App Store)

1. Открой `index.html` в Chrome
2. В адресной строке справа — значок ⊕ («Установить»)
3. Готово — отдельное окно, своя иконка, работает офлайн после первого запуска

## Что внутри

- **27 макетов**: карточки, плакаты, гроссбух, сетка, пилюли, список, цитата,
  билет, стикер, хронология, газета, облачко, рамка, дуотон, большая цифра и
  ещё десяток
- **Автогенерация палитр** — по цветовому кругу, гарантированно гармоничные;
  можно закреплять, инвертировать, редактировать вручную, сохранять в избранное
- **Распознавание цвета с фото** — загружаешь скриншот с цветовыми плашками,
  инструмент сам вытаскивает основные цвета
- **Подсветка любого слова** на обложке своим цветом (`**слово**` в поле названия)
- Свой шрифт, обводка/тень/градиент/неон на тексте
- QR-код, своё фото на любой слайд
- Undo/Redo (Ctrl+Z / Ctrl+Y), автосохранение черновика
- Дублирование/удаление/перестановка слайдов
- Счётчик символов подписи, банк хэштегов
- Тёмная/светлая тема самого инструмента
- Проверка контраста (WCAG AA/AAA)
- Превью «как в ленте Instagram»
- Экспорт: PNG одного слайда, zip со всеми, сохранение/загрузка проекта в файл

## Как загрузить это на свой GitHub (2 минуты, без командной строки)

1. Зайди на [github.com](https://github.com) → **New repository**
2. Дай имя (например `post-constructor`), оставь Public или Private — как хочешь
3. **НЕ** ставь галочку «Add a README» (он уже есть в архиве)
4. Нажми **Create repository**
5. На следующей странице увидишь ссылку **uploading an existing file** —
   нажми её
6. Перетащи мышкой все файлы из этой папки в окно браузера
7. Внизу нажми **Commit changes**

Готово — репозиторий у тебя на GitHub, с полной историей коммитов (каждая
функция добавлялась отдельным коммитом — видно в разделе *Commits*).

## Структура файлов

```
index.html         — сам конструктор (открывать этот файл)
build.py           — Python-скрипт, которым собран index.html (на случай правок)
qrcode_bundle.js    — библиотека генерации QR-кодов (встроена в index.html)
README.md          — этот файл
```

## Технические детали

- Чистый HTML/CSS/JS, без сборщиков и зависимостей на этапе запуска
- QR-коды генерируются локально (библиотека qrcode-generator, MIT-лицензия)
- Экспорт PNG — через canvas + SVG foreignObject
- Все данные (черновики, избранные палитры, тема) хранятся в localStorage
  браузера — только на твоём устройстве
