# SlideNav

The arrow pager under the slide preview: previous, a bold `3 / 10` counter, next.

**Use** once, centred under the preview stage.

**Consumer provides:** the two `<button>`s (← and →) and the `.count` text.

- Buttons use the ghost colours (`ui-border` fill, `ui-text`), 16px semibold, `radius-ui-tile`.
- The counter has a 70px minimum width so the arrows don't shift as numbers change.
