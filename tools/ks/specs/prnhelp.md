# Module `prnhelp` — «Помощник печати»
Integrate into the existing «Печать» (prep) tab: append cards when it renders (wrap `renderShop` or listen to `render` and inject when `activeTab==='prep'`, idempotently, without breaking it) + modals. Study `printNow`, imposition (`imposeAll`, `imposePages`), `st.shop.duplex/flip/printer`, `PRINTERS`, `dzOffsetWrap` (front/back offset correction), preflight.
- **Ручная двусторонняя печать** (G3410 has no auto duplex; GX4040 has auto but the user may choose manual): when a 2-sided job is printed and the printer/duplex setting means manual, show a wizard instead of one print dialog: «Шаг 1: печать лицевых сторон» (prints only odd/front sheets), then an illustrated step (inline SVG drawing of the printer, the stack and the flip direction for THIS printer's feed: G3410 rear tray / GX4040 cassette or rear tray) «Переверните стопку так…», then «Шаг 2: печать оборотов» (prints back sheets in the right order/rotation). Since feed/flip behaviour must be right for the real device, include a **«Пробный прогон»** calibration: prints 1 sheet with big «1 ↑ ВЕРХ» on the front, then after reinsertion a back with «2 ↑ ВЕРХ»; the user then picks which of 4 pictures matches what they see (back upside down? reversed order?) → stored per printer (`KS.store('prnhelp').duplex[printer]={rotateBack:bool, reverse:bool}`) and applied to all future manual duplex jobs. Long-edge vs short-edge flip from `st.shop.flip`.
- **Совмещение лица и оборота**: test sheet with fine rulers/crosshairs on both sides → user measures the shift (mm) → saved into the app's existing offset setting (find what `dzOffsetWrap` reads) with a preview.
- **Тест-страницы** (A4, KS.print): цветовая шкала (CMYK/RGB patches, 0–100% gray ramp, skin tones, gradients, fine lines, small text 4–8 pt) to check nozzles/quality; **проверка полей** for the current printer (rectangle along the printable boundary with mm labels from `PRINTERS`/`printArea`); **проверка масштаба** (100 mm squares and a ruler: «если не 100 мм — в окне печати выберите «Масштаб 100%»»).
- **Шпаргалка настроек печати** for the current job: computed from printer, paper (gsm/photo), borderless, duplex, quality — what to choose in the macOS / iPadOS print dialog (Тип носителя: Обычная бумага / Matte Photo Paper / Glossy / Плотная; Источник: задний лоток (GX4040 rear flat tray for ≥ 200 g/m²) / кассета; Качество; Без полей; Масштаб 100%; Двусторонняя). Shown as a compact card in the Печать tab and optionally as a pre-print sheet («Показывать перед печатью» toggle; uses `KS.on('beforePrint')` — the dialog must not block printing if dismissed).
- **Журнал печати**: every real print (`KS.on('print')`, not test) logged: date/time, product, template, qty, sheets, paper, printer, sides → table with filters (period/printer), monthly totals (sheets per printer), CSV export; «Повторить печать» for a log entry if the design is still in the project (store project id + design snapshot reference; at least reopen the product).
Tests: manual duplex wizard prints fronts then backs (capture both runs; backs rotated/reversed per stored calibration), calibration choice persists per printer, test pages have the exact sizes (100 mm square = 100 mm in DOM), print log entries after printNow (not after test print), cheat-sheet text changes with printer/paper, prep tab still works (core regression), screenshots light/dark/iPad.
