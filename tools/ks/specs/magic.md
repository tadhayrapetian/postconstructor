# Module `magic` — «Магия»: изменить размер, ремикс, палитры, цвет для печати
Entry: toolbar button «Магия» (KS.tool) opening a wide modal with tabs (seg): Размер · Ремикс · Палитры · Шрифтовые пары? (NO — fonts module does pairs) · Цвет для печати. Also ⌘K commands for each.
- **Магический размер**: pick target products (multi-select chips from `PRODUCTS` with `kind`, grouped by category, plus «Свой размер» W×H mm) → live thumbnails of the CURRENT design adapted to each size (treat the current design as a template: see `dzFromTpl(T,W,H,pal)`, `dzScaleEl`, `dzFit`, how templates adapt to dims; edge-touching backgrounds must stretch to the new edges, text keeps readable sizes and stays inside the safe zone, images keep aspect (cover), QR keeps square). «Открыть» switches to that product with the adapted design (keeps palette, fonts, brand data, both sides). «Сохранить все как мои шаблоны» (st.myTpl, check the existing save-template code for the format).
- **Ремикс**: grid of 12–16 variations of the current design rendered as thumbnails (`dzThumb`-like rendering of the modified doc): palette role rotations, dark/light inversion (`dzRoles(cols,dark)`), accent swaps, curated palettes that match the mood, font pair swaps (`DZ_PAIRS`), background variants (solid/soft/gradient). «Ещё варианты» reshuffles deterministically by a counter. Click → apply (one undo step). Check `dzVariants` (existing) and build on it rather than duplicating.
- **Палитры**: library of ≥ 150 curated, named palettes (5 colours each; themes: свадьба, детский, эко, люкс/золото, кофе, кондитерская, медицина, бьюти, техно, осень, зима, весна, лето, море, Армения (гранат, абрикос, Арарат), новый год, пастель, неон-для-экрана (mark as not print-safe), винтаж, минимализм, корпоративные синие…); search, filter by mood/light-dark, «★». **Генератор гармоний** from a base colour (colour wheel UI + hex input + eyedropper where `window.EyeDropper` exists): комплементарная, аналоговая, триада, тетрада, раздельно-комплементарная, монохром; Coolors-style row with lock 🔒 per colour and «Перемешать» (Space). Apply via `dzSetPalette(cols,name)`.
- **Цвет для печати**: detect colours in the design (palette roles + custom colours on elements) that are outside a typical CMYK inkjet gamut (approximate: convert to CMYK naive and back / check high chroma in sRGB like #00FF00, #FF00FF, #00FFFF, vivid blue/violet/orange; implement a reasonable gamut test and explain it is approximate) → list with swatches «на экране → на бумаге» (simulated), «Сделать печатным» (nearest in-gamut colour by reducing chroma in Lab/LCh until in gamut), «Исправить все». Add these warnings to the app's preflight too (find how preflight `add(level,msg)` works — e.g. wrap `dzPrinterChecks(add)` like extra.js does). **«Как будет на бумаге»** soft-proof toggle (KS.tool or in the modal): applies a CSS filter/overlay on the live layout (`#inner`) simulating inkjet on the chosen paper (офисная: less contrast & saturation, slightly darker; фотобумага: closer to screen) — screen only, never printed.
Tests: magic resize of a business card to A5 flyer/round sticker keeps elements inside bounds and fonts sane (assert numbers), remix thumbnails differ and applying changes the palette, palettes count ≥ 150 and apply, harmony math (complementary hue = +180°), gamut detection flags #00ff00 and not #336699, fix produces in-gamut colours, preflight lists the warning, soft-proof not present in print capture; screenshots light/dark/iPad.
