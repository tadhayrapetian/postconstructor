# Module `stats` — «Сводка»: обзор бизнеса, доска заказов, сроки
Rail: group `svodka`, groupTitle «Сводка» (icon: chart), before `orders`. Tabs (all `screen:true`): `seg:'Обзор'`, `seg:'Доска'`, `seg:'Сроки'`. Side panel holds filters/period/actions.
First study the existing orders feature (`st.orders`, `ORD_ST`, `newOrder`, `renderOrders`, order editor/`ordOpen`, clients) so you can open an order in the existing editor from your screens.
- **Обзор**: period selector (Сегодня / Неделя / Месяц / Квартал / Год / Всё / свой период) with comparison to the previous period (▲▼ %). KPIs: Выручка (money received), Заказов, Средний чек, В работе, Готово к выдаче, Просрочено, Долги клиентов (сумма price−paid по невыданным/выданным), Себестоимость и прибыль (if `order.cost` filled). Charts (hand-made SVG, crisp, theme-aware, with hover/tap tooltips): выручка по дням (bars, 30/90 days), структура по изделиям (donut or horizontal bars, top 8 + «прочее»), способы оплаты (if pos data exists), загрузка по дням недели; tables: топ клиентов, топ изделий. Revenue rules exactly as HOST.md "Money received": sum of `order.paid` attributed to the order date, plus pos sales of type `sale` (and minus `refund`), never adding pos `order` payments again. Explain the rule in one hint line. If the `dataviz` skill is available to you, load it before drawing charts.
- **Доска** (kanban): columns Новый / В работе / Готов / Выдан (+ collapsed Отменён); cards: №, client, product, qty, due date chip (red overdue, orange today/tomorrow), money badge (оплачен / долг N ֏), note snippet. Drag & drop between columns with pointer events (mouse + iPad touch, auto-scroll), updates `status` (+ save, toast with «Отменить»). Card tap opens the existing order editor (Заказы tab). Quick actions on a card: «Позвонить» (`tel:`), «Написать в WhatsApp/Telegram» (`https://wa.me/<digits>?text=…` «Здравствуйте! Ваш заказ №… готов. …» using shop name), «Готов»/«Выдан». Filters: search, client, only overdue, only unpaid.
- **Сроки**: month calendar with due-date dots/counts (colour by status), click a day → list; «Неделя» agenda view; export deadlines to `.ics` (download; Apple Calendar on Mac/iPad imports it), only not-done orders, with reminders 1 day before.
- Exports for the period: CSV and Excel (`loadLib` xlsx 0.18.5) of orders and sales.
- Rail badge: number of overdue orders on the «Сводка» button (small red dot with count), refreshed on `render`.
Must handle empty data beautifully (friendly empty states + «Создать заказ»), and large data (500 orders) fast.
Tests: seed 60 orders across 3 months with various statuses/paid + pos sales incl. order payments and refunds, assert KPI numbers by independent calculation in the test, drag a card between columns with mouse and with touch, ICS file content valid (BEGIN:VCALENDAR, DTSTART dates), CSV columns, badge count, screenshots light/dark/iPad for all three screens.
