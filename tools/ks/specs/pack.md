# Module `pack` — «Упаковка и вырубка»: развёртки коробок и изделий сложной формы
Entry: a button in the Шаблоны panel area (insert a card at the top of the shop/templates panel when it renders — wrap `renderDzShop` safely), toolbar ⌘K «Развёртка коробки», and a KS.tool «Развёртка» only when a dieline design is open.
- **Генератор развёрток** (wide modal with live SVG preview + parameters in mm): Коробка с клапанами (tuck end: длина×ширина×высота, толщина картона), Коробка крышка-дно, Коробка-подушечка (pillow), Бумажный пакет с дном и боковыми складками, Конверт-кармашек для открытки/денег, Конверт для денег (Armenian/Russian wedding tradition — popular), Бирка с отверстием, Хенгер на дверь (door hanger 90×230 with hole), Тейбл-тент (домик), Обечайка/бандероль, Коробочка для визиток, Пирамидка/сундучок? (optional). Each: cut lines, fold lines, glue flaps, dust flaps, rounded tuck tongues, thumb notch, correct geometry (flaps lengths, clearances for paper thickness).
- Fit check: flat size vs printable area of A4 (210×297 minus printer margins, `printArea`) and A3; if too big — tell the max dimensions for this box type and offer «Уменьшить пропорционально». Show sheet usage (how many fit on A4).
- **Создать макет**: creates a design (custom product size = flat bbox; study how the app sets custom sizes, `applyProduct`, `dzBlank`, `st.dz.w/h`) with a non-movable, locked **dieline layer** (new element type, e.g. `t:'die'`, rendered by wrapping `dzElHTML`): cut = solid magenta/red, fold = dashed, glue = hatched, panel names («Перед», «Зад», «Верх», «Бок», «Клей») as faint labels — all visible in the editor; in print/export: option «Печатать линии реза и сгиба» (thin 0.2 mm grey; default ON because the operator cuts by hand) while panel names/hatching never print. Panel safe-areas help placing elements (optional guides). Background colour/image fills the whole flat shape with bleed beyond cut lines.
- **3D-предпросмотр** of the folded box (CSS 3D: faces cropped from the rendered design, drag to rotate, auto-rotate, works on iPad) — the wow feature; at least for tuck-end box, lid box and table tent.
- Print: dieline designs should print 1 per sheet at 100% (or as many as fit), with the existing print pipeline; make sure imposition doesn't break (if the app's imposition can't handle it, use `KS.print` with an exact page).
Tests: geometry sanity (flat size formulas for tuck end box: width = 2L+2W+glue, etc. — assert), SVG paths present, create design → element type die renders in editor, print capture includes cut/fold lines (when ON) and excludes labels; 3D preview opens and rotates; fit warning for a too-large box; screenshots light/dark/iPad.
