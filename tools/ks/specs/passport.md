# Module `passport` — «Фото на документы»
Rail: group `salon`, groupTitle «Фотосалон» (icon: camera), before `prep`, this tab `seg:'Документы'`, `screen:true` (big cropper on the screen; side panel = format, adjustments, layout, print, order).
Workflow:
1. Load a photo: file picker (iPad: camera/photo library via `accept="image/*"`), drag-drop, paste, or pick from «Мои фото» (IndexedDB photo library per HOST.md, if present).
2. **Format presets** with correct specs (photo size mm, head height range chin→crown mm, top margin crown→top edge mm, background colour; verify from your knowledge of official rules and use WebSearch if available): Паспорт РА / ID-карта РА (35×45), Паспорт РФ (35×45), Загранпаспорт РФ (35×45), Шенген (35×45), Виза США / Грин-карта DV (51×51, 2×2″), Великобритания (35×45), Канада (50×70), Китай виза (33×48), Индия (51×51), 3×4 (30×40, справки/пропуска/студбилет), 4×6, 9×12, 10×15; plus «Свой размер». Show a short spec line for the chosen preset.
3. **Cropper** on the screen at the exact aspect: drag to pan, wheel/pinch to zoom, rotate/straighten slider (±15°), with overlay guides: face oval, crown line and chin line band (allowed range from the preset), eye line band, vertical centre line, «уголок» guide if the preset uses it. **Two-tap fit**: «Отметить макушку и подбородок» → user taps the crown, then the chin on the photo → the app scales and positions automatically to the preset's ideal head height and top margin. Keyboard arrows nudge on Mac.
4. **Adjust**: яркость, контраст, тёплый/холодный, «Авто», Ч/Б option. **Фон**: «Осветлить фон» to white / светло-серый / светло-голубой — region-grow from the borders with tolerance and feather sliders, preview; never touch the face (stop at strong edges).
5. **Layout & print**: sheet choice 10×15 photo paper (default), 13×18, A4, or «Один снимок»; number of photos (e.g. 4/6/8/«на весь лист»), gap, thin cut lines/marks; centred layout; preview on the screen (toggle Кадр/Лист). Print with `KS.print` (exact page size). Printer awareness: G3410 can print borderless on photo paper 10×15/13×18/A4; GX4040 has no borderless (5 mm margins) — layout must stay inside the printable area of the current printer (`KS.printer()` / `printArea`). Show «Печатайте на фотобумаге, масштаб 100%».
6. **Export**: JPEG of a single photo at 600 dpi and of the sheet at 300 dpi (`KS.download`), «В мои фото» (album «Документы»).
7. **Заказ**: price per set (editable, `KS.store('passport').price`, default e.g. 1500 ֏ for 4–6 photos) → «Добавить в заказ» uses `newOrder({...})` with product «Фото на документы», qty, price; or «В кассу» if the `pos` module exists (`KS.emit('posAdd',{name,price,qty})` — the pos module listens; harmless if absent).
8. Remember the last preset and settings; keep the current job while switching tabs (not in undo history).
Quality: it must be precise (mm-exact), fast, beautiful, touch-friendly on iPad. The cropper is the hero — smooth 60fps panning (CSS transforms, no re-render on every move).
Tests: synthetic portrait (draw a face-like ellipse with eyes on a grey background), two-tap fit gives head height within the preset range, sheet layout count/positions in mm (inspect print capture DOM), background whitening raises border brightness but keeps the centre unchanged, exports produce correct pixel sizes (35×45 at 600 dpi = 827×1063), order creation, iPad pinch (simulate via touch events or wheel), screenshots light/dark/iPad.
