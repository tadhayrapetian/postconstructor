# Module `layout` — профессиональные инструменты макета
Study the editor first: `dzDown/dzMove/dzUp`, `dzSel`, `dzSelect`, `dzOverlay`, `dzSnap`, `dzGuides`, `dzKey`, `dzAlign`, `dzOrder`, `dzDup`, `dzDelete`, layers panel (`renderDzLayers`), `dzBar`. Integrate WITHOUT breaking single-element editing (the existing behaviour and tests t21/t18 must still pass).
- **Мультивыделение**: Shift+click / ⌘(Ctrl)+click toggles elements; **рамка выделения** by dragging on an empty area of the layout (and on iPad: long-press + drag, or a «Выделить несколько» mode button); ⌘A selects all on the side; Esc clears. A combined selection box with 8 handles: move together (mouse/touch/arrow keys with Shift = 10 mm step... use the app's step), proportional scale of the whole selection (text sizes scale too), delete, duplicate (⌘D), copy/paste (⌘C/⌘V within the app; works across sides), hide/lock all, bring forward/back.
- **Группы**: «Сгруппировать» (⌘G) / «Разгруппировать» (⇧⌘G) — store `e.grp` id; a click on a grouped element selects the whole group; double-click inside a group selects the single element (and double-click text still edits text).
- **Выравнивание и распределение** for multi-selection: по левому/центру/правому, верху/середине/низу (relative to the selection bbox, or to the page when one element or when «относительно листа» is on), **распределить** по горизонтали/вертикали с равными промежутками, «одинаковая ширина/высота». Inspector for multi-selection shows X/Y/W/H of the bbox (editable) + these buttons.
- **Линейки** (top & left, mm, zoom-aware, follow pan/zoom, theme-aware, hidden in print and in the envelope mode) and **направляющие**: drag from a ruler to create a guide, drag to move, drag back to the ruler or double-click to delete; guides stored in `st.dz.guides=[{o:'v'|'h',p:mm}]` per design; elements snap to guides (wrap `dzSnap` or equivalent) and to other elements' edges/centres; show **smart spacing** hints (equal gaps highlighted, distance labels in mm while dragging). Toggle «Линейки» in the toolbar.
- **Найти и заменить** (modal, ⌘F in Макет): search text across front/back, replace one/all, match case, whole words.
- **Горячие клавиши** cheat sheet modal (? key / ⌘K command) listing all shortcuts incl. new ones.
- Everything undoable as single steps; nothing of this is printed.
Tests (mouse AND touch): shift-click 3 elements, drag them together (positions shift equally), marquee select, align left/distribute horizontally numerically correct, group then click selects group, double-click edits text inside group, ruler guide create/move/delete + snapping to it, find/replace, keyboard shortcuts in both layouts (use `ev.code`, like the app), undo/redo, print capture contains no rulers/guides/selection; core regression `ks/regress.sh` passes; screenshots.
