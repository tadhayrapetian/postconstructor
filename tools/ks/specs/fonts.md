# Module `fonts` — «Шрифты»: свои шрифты, пары, удобный выбор
First study how fonts work now: the legacy envelope mode already supports user fonts (`st.fonts`, `registerFont`, `refreshFontSelects`), the design studio uses `st.dz.fonts.{h,b}`, `dzFont`, `dzFontOpts`, `FONTS`/font maps (search the app), Google fonts list in the page head, and the separate print/export documents (search `links` and `styles` used when printing on iPad / in `pageCanvas` export — custom fonts must work there too, i.e. you may need to inject `@font-face` rules with data URLs).
Features:
- **Менеджер шрифтов** (modal, opened from toolbar button «Шрифты», ⌘K, and a link in the Макет panel next to font selects): searchable list of ALL available fonts with live preview line (sample text editable; default uses the selected text element or «Съешь ещё этих мягких французских булок · Բարև · Hello 123»), size slider, filters: С кириллицей, С армянским, Без засечек, С засечками, Рукописные, Декоративные, Мои; ★ избранные (favourites float to the top of font selects).
- **Загрузка своих шрифтов**: TTF/OTF/WOFF/WOFF2, multiple files, drag-and-drop; store the binary in IndexedDB (`KS.idb` store `files`, key `font:<id>`), NOT in `st` (localStorage limit); register with `FontFace` at boot and on upload; detect family/style name from the file (parse the `name` table of TTF/OTF; fall back to the file name); detect Cyrillic/Armenian coverage (e.g. compare glyph widths vs a fallback font on canvas, or cmap parse); delete font. Custom fonts must appear in the Макет font selects (wrap `dzFontOpts`) and render in layout, print, PNG/PDF export. If a design uses a custom font that is missing (other device), preflight should warn (check how fonts are checked now).
- **Пары шрифтов**: ≥ 30 curated heading/body pairs (from fonts available in the app, incl. ones with Cyrillic & Armenian support), shown as cards rendered with the current design's heading/body texts; one tap applies `st.dz.fonts` (update). Group by mood: Строгие, Элегантные, Дружелюбные, Смелые, Ретро, Праздничные.
- In the inspector for text elements: «Похожие шрифты» quick row (5 alternatives in the same class).
Tests: upload a real TTF (generate one or take a .ttf/.woff2 from `$S/fonts/*/package/files` and convert if needed), verify it registers, shows in selects, renders in print capture and export PNG (pixel diff vs fallback), survives reload (re-registered from IndexedDB), delete works; pairs apply; screenshots.
