# Module `imgfx` — фото-редактор в «Макете»
Inspector section (`KS.insp`, for `img` elements with a picture, also for the logo slot where sensible) titled «Обработка фото», plus a big modal editor «Редактор фото» (`KS.modal` full) opened from the section and by double-click+Alt or a button.
Features:
- Adjustments with sliders: Яркость, Контраст, Насыщенность, Теплота (temperature), Оттенок, Светлые/Тени (highlights/shadows), Резкость (unsharp mask), Размытие, Виньетка, Зерно. Toggles: Ч/Б, Сепия, Инверсия.
- One-tap presets with live mini-thumbnails of THIS photo: Авто, Для печати (inkjet compensation: lift midtones/gamma ~+8–10%, slight saturation and sharpening — inkjet prints come out darker than the screen), Ч/Б, Ч/Б контраст, Винтаж, Тёплый, Холодный, Яркий, Мягкий, Кино, Плёнка, **Дуотон** (two colours from the design palette — great for print designs), Сепия.
- «Авто-улучшение»: per-channel auto levels (0.5% clip) + mild contrast/saturation.
- «Убрать фон»: (a) «Убрать белый фон» one tap for logos/scans; (b) colour key: pick the background colour by tapping the photo in the editor (default: average of the 4 corners), tolerance + edge softness sliders, «Только по краям» (flood fill from borders so that same-colour areas inside the object stay). Output PNG with alpha. Show transparency checkerboard in the editor.
- Crop & rotate in the modal: free / product-ratio / 1:1 / 3:4 / 4:3 / 2:3 crop with draggable handles (touch), rotate 90°, straighten slider (−15…+15°), flip H/V.
- Shapes/masks for the element (non-destructive, live on the layout and in print/export): круг, овал, скруглённый прямоугольник (radius), арка, сердце, звезда, шестиугольник, капля, облако, ромб — via CSS `mask-image`/`-webkit-mask-image` with an SVG data URL or `clip-path`. Check how the app already renders `mask` (circle/arch) in `dzElHTML` and extend consistently. VERIFY masks appear in: the live layout, print (`#printRoot` via KS.print or printNow capture), and the PNG export path (`pageCanvas` / SVG foreignObject and the html2canvas fallback `pageCanvasH2C`). If a path can't render a mask, bake it into the image for that path or bake by default — but it must look right everywhere.
- Frame: stroke colour/width (exists as `stroke`/`sw` for img — reuse), shadow toggle (soft drop shadow), «Полароид» white frame.
- Before/after: press-and-hold «До» to see the original.
- Non-destructive: keep the ORIGINAL picture in IndexedDB (`KS.idb` store `files`, key `fx:<hash-or-uid>`), store params on the element (`e.fx={…, o:'fx:…'}`), and bake the processed result into `e.src` (≤ 3200 px, JPEG 0.9 or PNG when alpha). «Сбросить обработку» restores the original. Sliders preview on a downscaled proxy while dragging (fast), bake full-size on release (debounced); never block the UI for long (show a small spinner).
- Print-quality info line: effective dpi of the photo at its current size on the layout («≈ 280 dpi — отлично»).
Must work on iPad (touch sliders, crop handles), in light and dark themes. Keep every operation undoable (one undo step per committed change).
Tests: synthetic photos (gradients/shapes drawn in canvas, a logo on white, a portrait-like image), verify pixel results numerically (e.g., brightness raises mean, white background → alpha 0 at corners and alpha 255 in object), masks visible in print capture and in exported PNG (sample pixels outside the mask = background), reload keeps the result, undo/redo works.
