# Module `home` — «Главная»: стартовый экран типографии
Rail: group `home`, title «Главная» (icon: house), before `shop`, `screen:true`. Side panel: «Сегодня» summary + search. Big screen: dashboard.
- **Hero**: greeting by time of day + shop name (`st.shop.name` or «Типография»), today's date, small KPIs: заказы к выдаче сегодня, просрочено, оплачено сегодня (orders paid today by order date + pos sales today if `st.ks.pos` exists — compute defensively), low stock count if `st.ks.stock` exists.
- **Быстрые действия** (large beautiful tiles with icons, 2–4 per row responsive): Новый заказ (existing order flow), Визитки, Листовка, Наклейки, Приглашение, Фото на документы (`KS.show('salon','passport')` if that module exists — check `KS.mods`), Печать фото, Касса, Найти фото, Все шаблоны, Продолжить макет (thumbnail of the current design rendered small with `dzHTML` scaled or `dzThumb`), Проверить и напечатать. Tiles for absent modules are hidden. Product tiles call `applyProduct(id)` and open the templates tab.
- **Сегодня и ближайшие сроки**: list of orders due today/tomorrow/overdue with status chips; tap → opens the order.
- **Последние проекты** (`proj.list`) and **последние шаблоны** used (track in `KS.store('home').recent` on `select`/template apply events — wrap `dzApplyTpl`).
- **Поиск по всему** (side panel + `/` shortcut when Главная is open): templates (by name/tags across `DZT` + `st.myTpl`), products, orders (№, client, phone), clients, commands (`allCmds()`); grouped results with keyboard navigation; Enter opens.
- **Подсказки** («Знаете ли вы?») carousel of 10–15 tips about features (including new modules if present: Фото, Магия, Касса, Склад…) with «Показать» buttons.
- Setting (in the side panel bottom): «Открывать Главную при запуске» (default ON) — on `boot` in Типография mode, open Главная (but do NOT steal focus or break when a project restore dialog/tour is shown; and don't switch tabs on later renders).
Must look premium: generous spacing, crisp icons, subtle gradients using `--accent`, great in dark mode, responsive down to iPad portrait (820 px) and phone width.
Tests: tiles open the right places (assert `activeTab`/`st.prod`), search finds a template/order/command and opens it, KPIs computed correctly from seeded data, boot opens Главная when enabled and not when disabled, core regression (`ks/regress.sh`) still passes with home opening at boot — if a regression test assumes a starting tab, make home's boot behaviour robust (e.g. only on real user boot: skip when `navigator.webdriver` is NOT a valid reason — instead make the regression pass by not interfering with tabs the tests click), screenshots light/dark/iPad/portrait.
