# Module `texts` — «Тексты»: готовые поздравления, слоганы, формулировки + ИИ-помощник
Entry points: toolbar button (KS.tool) «Тексты»; inspector section for `text` elements with a button «Подобрать текст»; ⌘K commands. UI = a wide modal (`KS.modal({wide:true})`): left = categories + search + language filter (Русский / Հայերեն / English), right = cards.
Library (write ORIGINAL texts — no copying of known poems/authors; natural, warm, correct Russian; correct Armenian with proper Armenian script and punctuation; good English):
- Russian ≥ 320 entries, English ≥ 60, Armenian ≥ 60 (short greetings, wishes, invitations, signs — keep Armenian simple and correct).
- Categories (each with several sub-cases): День рождения (общее, женщине, мужчине, ребёнку, коллеге, маме/папе, бабушке/дедушке, юбилеи 18/30/40/50/60/70/80), Свадьба (приглашение, поздравление, благодарность гостям, рассадка), Рождение/крестины, Новый год и Рождество, 8 Марта, 23 Февраля, День матери, День учителя, Выпускной/Последний звонок/1 сентября, Валентинка, Благодарность (коллегам, врачу, учителю, клиентам), Корпоратив, Приглашения (вечеринка, открытие, презентация, детский праздник, мастер-класс), Соболезнование и память (тактично), Сертификаты/грамоты/дипломы (формулировки «Награждается…», «За…»), Подарочные сертификаты, Слоганы для бизнеса (кафе, кондитерская, салон красоты, барбершоп, автосервис, магазин, доставка, юрист, бухгалтер, фитнес, клиника, стоматология, клининг, фото-студия, типография, детский центр, туризм, недвижимость), Тексты для визиток (подписи под именем, описания услуг), Акции и скидки (листовки), Таблички и объявления (Режим работы, Не курить, Мы открыты, Перерыв, Вход/Выход, WC, Осторожно ступенька, Оплата картой, Wi-Fi пароль…), Этикетки/ценники/бирки (Ручная работа, Состав, Срок годности…), Меню (описания блюд-шаблоны), Свадебные мелочи (бонбоньерки, таблички столов).
- Each entry: `{id, cat, sub, lang, title?, text, tags[], len:'s'|'m'|'l', kind:'prose'|'verse'|'slogan'|'sign'}`; texts may contain tokens `{имя}`, `{дата}`, `{время}`, `{место}`, `{компания}`, `{телефон}`, `{сумма}` — the app already supports `{имя}`-style tokens for batch data: check `dzText` and reuse/keep compatible.
- Put the library data in the module (can be a big JSON literal; keep mod.js < 400 KB).
Actions on a card: «Вставить» (replace the selected text element's text; if none selected, add a new text box sized to the text), «Копировать», «★» favourite, token fill form («Имя: …») before insert, «Ещё похожие». Search (ё-insensitive), filters by length and kind, «Избранное», «Мои тексты» (save your own, edit, delete; `KS.store('texts')`).
Smart: when the current product/template is e.g. a wedding invitation or a business card, open the matching category first (use `prodById(st.prod)` kind/category and template name).
**ИИ-помощник** (optional, clearly marked): settings with a Claude API key field (stored ONLY in `localStorage['ks-ai-key']`, never in `st`/project files/backups; warning that the key gives access to their paid account; «Удалить ключ»). Form: повод, кому, имя, тон (тёплый / официальный / весёлый / трогательный / в стихах), длина, язык, доп. пожелания → POST `https://api.anthropic.com/v1/messages` with headers `x-api-key`, `anthropic-version: 2023-06-01`, `anthropic-dangerous-direct-browser-access: true`, `content-type: application/json`; body `{model, max_tokens: 1200, messages:[…]}`; model select: `claude-sonnet-5-5` (default), `claude-haiku-4-5-20251001` (быстрее и дешевле), `claude-opus-5-5`. Ask for 3 variants as JSON; parse robustly; show as cards with the same actions. Handle errors (401 bad key, 429, 529 overloaded, network) in Russian. Also «Улучшить текст» for the selected element (fix grammar / shorten / make more festive / translate to Armenian/English).
Tests: library counts by language, search, insert/replace with tokens, favourites/my texts persist, smart category, AI flow with mocked API (success + 401 + malformed), key never appears in `JSON.stringify(st)` or project export; screenshots (light/dark/iPad).
