# Module `qrpro` — QR-мастер и штрихкоды
The app already has `qr` and `bar` design elements (see `dzElHTML`, SCHEMA.md; qrcode-generator 1.4.4 `qrcode` and `JsBarcode` are loaded). Extend them.
- **QR-мастер** (modal, opened from: inspector section for `qr` elements «Настроить QR», toolbar/⌘K «QR-код», and when adding a QR): content types with forms and validation: Ссылка, Текст, Телефон (`tel:`), SMS (`SMSTO:`), E-mail (`mailto:` with subject/body), **Wi-Fi** (`WIFI:T:WPA;S:…;P:…;H:false;;` with escaping of `\;,:"`), **Визитка vCard 3.0** (prefilled from the design's client data `st.dz.brand` — company, name, title, phone, email, site, address; UTF-8 Cyrillic/Armenian ok), **Геоточка** (`geo:lat,lng` or a maps link; parse a pasted Google/Yandex/Apple maps URL), Telegram (`https://t.me/…`), WhatsApp (`https://wa.me/<digits>?text=`), Instagram, Viber, **Событие** (VEVENT: title, start/end, place), Оплата/реквизиты как текст. Live preview, character count and QR version/density indicator («плотный — печатайте не меньше 20 мм»).
- **Стиль** (vector SVG, must print crisp): modules — квадраты, точки, скруглённые, классические соединённые («liquid»), ромбы; глазки (finder patterns) — квадрат, скруглённый, круг, лист; colours from palette roles or custom, optional gradient; transparent or solid background; quiet zone; **логотип в центре** (brand logo or upload; forces error correction H; clears modules behind it); **рамка с подписью** («Сканируй меня», «Меню», «Wi-Fi», «Оплата», custom) in several frame styles. Store style in `e.qs={…}`, data in the element's existing field (check what the app uses, e.g. `e.text`/`e.v`); wrap `dzElHTML` for `qr` elements with `e.qs`, keep backward compatibility for old QR elements.
- **Проверка**: contrast ratio warning (dark on light needed; inverted QR warning), minimum size warning (< 15 mm), quiet-zone warning; add these to the app preflight (wrap `dzPrinterChecks(add)` like extra.js).
- **Штрихкоды** inspector for `bar` elements: type EAN-13 (auto check digit, validation), EAN-8, UPC-A, Code 128, Code 39, ITF-14; show/hide digits, font size, bar height, colours; invalid input shows a clear error instead of breaking the layout.
- **Серия**: «Нумерация QR/штрихкодов» — the app supports numbering tokens like `{№:000}` for batch printing (find how: `recNum`, batch records, tokens in `dzText`); make QR/barcode values support the same tokens so a sheet of numbered labels/tickets with unique codes prints correctly (check imposition with qty > 1 gives different codes per item).
Tests: generate each content type and DECODE the rendered QR to verify the payload (install `jsqr` via npm into `$S/npmx` or another scratch dir if the network allows; otherwise decode with your own check by re-reading the module matrix from the qrcode object), vCard with Cyrillic decodes, logo QR still decodes (H level), styled QR SVG appears in print capture as vector (svg rects/paths, not img), EAN-13 check digit, numbered series produce different codes per item in print capture, screenshots light/dark/iPad.
